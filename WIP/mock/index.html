Deviator · throwaway mocks · one page per flow state
Tap through in flow order. Flow choices travel in the URL, so each page shows the state it was reached with. Not production code. Known mock limits: leaving and re-entering a measurement resets its values (the real app resumes exactly), the system back button is not trapped, and the variation / reference pickers are simple toggles.
1 · start
Logo, statement, START, saved tables, settings
2 · setup
Precision, starting heading, direction, COG reference
3 · measure
One heading at a time: steer, tape, COG, lights, PREV / NEXT / ABORT
4 · measure, all visited
All lights on, ABORT has become FINISH
5 · finish choices
Continue other direction / Finish / Abort
6 · confirm destructive action
Full screen, hold to confirm (abort, delete, reset)
7 · review, two rounds
Curve, per-heading rows, approve and save
7b · review, one round
Same screen with a single direction measured
8 · review, one heading
Starboard only / port only / both / re-measure
9 · save
Boat, date, reference, variation; saved tables are final
10 · deviation table
Curve, table, converter, share, settings, close
11 · saved tables
Tables by boat; open or delete
12 · settings
Theme, language, debug GPS, erase everything
